# Sistem-Informasi-klinik
Sistem Informasi Klinik adalah proyek kelompok semester 2 yang dikembangkan oleh tim beranggotakan 4 orang. Proyek ini bertujuan untuk membangun sistem pengelolaan klinik yang mencakup manajemen pasien, dokter, jadwal pemeriksaan, rekam medis, obat, serta laporan administrasi guna meningkatkan efisiensi pelayanan klinik.
